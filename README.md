# Simple Interest Calculator

A Bash script that calculates simple interest from user input.

## Description
This project contains `simple-interest.sh`, a command-line calculator. It asks for the principal, the rate of interest, and the time period, then prints the simple interest.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: the starting amount
- Rate of interest: the annual rate, in percent
- Time period: the duration, in years

## Usage
    chmod +x simple-interest.sh
    ./simple-interest.sh

## Requirements
- Bash
- bc (for decimal arithmetic)
